# Paper Method Analysis（论文研究 Buddy）

一个覆盖科研写作全链路的 Skill（方法梳理 / 文献查找 / 论文润色 / 论文帮写），外加一个可直接体验的在线交互页。

核心思路：**不替用户读论文，而是先确认研究视角，再做有针对性的方法脉络梳理**——同样一批论文，关注"轻量化"和关注"可解释性"的人需要的技术脉络完全不同。

## 目录结构

```
.
├── paper-method-analysis/          # Skill 源码（可直接安装使用）
│   └── SKILL.md                    # Skill 定义：角色 / 核心铁律 / 四模块路由 / 引用核验
├── paper-method-analysis.skill     # 打包产物（zip，内容为上面的 SKILL.md）
├── method-buddy-demo/              # 在线体验页（单文件，无构建）
│   └── index.html                  # 四大类交互演示 + 会话持久化 + 自定义鼠标 UI
└── skill-gap-analysis-report.md    # Skill 差异分析报告
```

## 一、Skill 源码（`paper-method-analysis/SKILL.md`）

### 四个能力模块（按意图路由）

| 模块 | 触发意图 | 关键行为 |
|---|---|---|
| **A. 论文方向分析** | 梳理方法、技术路线、演进脉络、推导研究方向 | 阶段一核对四项要素（≥2 项不明则追问）→ 阶段二最多追问两轮 → 阶段三按四部分输出 |
| **B. 文献查找** | 找论文、查文献、某方向有哪些工作 | 双库检索，字段一律来自 API；年份区间不合理先提醒；结果需用户勾选确认 |
| **C. 论文润色** | 润色、改写、校对、让这段话更学术 | 确认修改角度（最多一轮）→ 先诊断 → 逐段改并给修改说明 → 迭代确认 |
| **D. 论文帮写** | 帮我写论文、起草综述/课程论文 | 八项信息收集（无上限追问 + 收尾清单）→ 文献须勾选 → 写作方案待批准 → 生成 → 交付假设清单 |

模块 A 阶段三输出固定为四部分：方法分类汇总（表格）/ 技术演进梳理 / 研究方向推导 / 需确认的假设。

意图混杂时按顺序执行（如先 B 检索、再 A 梳理），两阶段之间需用户确认。

### 引用真实性铁律

输出中凡是出现具体文献题名或「作者+年份」的引用，必须先经 **OpenAlex / Crossref** 反查核验再写入，按题名 token 的 Dice 相似度 + 年份差判定：

| 判定 | 条件 | 处理 |
|---|---|---|
| ✅ 存在 | 相似度 ≥0.9；或 ≥0.7 且年份差 ≤2 | 正常写入，可附 DOI |
| ⚠️ 存疑 | 相似度 0.35–0.7 | 不写入，或显式标注「未核实」 |
| ❌ 未找到 | 相似度 <0.35 或两库均无记录 | **必须删除**，并告知用户 |

核验接口不可用时，不臆造引用，改用「基于通用知识」表述。

### 安装使用

把 `paper-method-analysis/` 目录放到你的 skills 目录下即可（各客户端路径不同，例如 `~/.codebuddy/skills/`）。也可直接解压打包产物：

```bash
unzip paper-method-analysis.skill -d ~/.codebuddy/skills/
```

## 二、在线体验页（`method-buddy-demo/index.html`）

单文件原生 JS 应用，无构建、无依赖，双击即可打开。

### 四大类功能

| 大类 | 模式 | 说明 |
|---|---|---|
| 论文方向分析 | 演示 / 真实 | 三阶段引导式方法梳理，输出方法表格 + 方向卡片 + 技术演进时间线 |
| 文献查找 | 仅真实 | 调用 OpenAlex / Crossref 检索，结果以真实表格列出并支持勾选入库 |
| 论文润色 | 仅真实 | 四阶段润色流程，支持粘贴文本或上传 docx / pdf |
| 论文帮写 | 仅真实 | 五阶段写作流程，需用户勾选确认文献后才引用，杜绝编造 |

### 关键特性

- **会话持久化**：基于 IndexedDB（`methodbuddy` v2 库），会话、上传文件、文献库刷新/关闭后均保留
- **右侧会话面板**：DeepSeek 风格，四大类各自独立的会话列表，支持重命名与删除
- **会话重命名**：手动命名后锁定，自动改名不再覆盖
- **竞态防护**：回复生成期间新建对话，回复仍准确落回原会话
- **鼠标 UI**：自定义光点光标（惯性拖尾）+ 悬停柔光环 + Material 风格点击水波纹
- **年份区间校验**：用户输入不合理区间时给出提醒

### 本地运行

```bash
cd method-buddy-demo
python3 -m http.server 8901
# 打开 http://localhost:8901/index.html
```

真实对话模式需在页面左侧「⚙ API 设置」中填入 LLM 接口地址、Key 与模型名（配置保存在浏览器本地）。演示模式无需任何配置。
